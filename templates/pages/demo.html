Demo Best Practices

1. Always pre-run the demo. Execute all notebooks and reset state the night before. Never run a cold cluster live.
2. Use realistic data. Anonymized customer-like data creates more impact than synthetic toy datasets.
3. Tell a story. Frame the demo around the customer's problem — not Databricks features. Start with the pain, end with the outcome.
4. Keep a backup. Pre-render outputs and have a static walkthrough PDF in case of connectivity issues.
5. Follow up fast. Send a recap with the demo notebook link within 24 hours of the session.
